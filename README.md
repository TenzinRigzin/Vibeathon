# Vibeathon

Personal Career Navigator — AI career co-pilot (Angular).

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 20.3.10.

## Development server

```bash
ng serve
```

## Build

```bash
ng build
```

## Running unit tests

ng test
